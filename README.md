## 📌 Overview

Epilepsy detection from brain data can support earlier diagnosis. This repository holds the dataset and the trained models built to explore that problem.

## 📂 Repository structure

```
Brain_Epilepsy/
├── all models/   # trained model files
├── dataset/      # epilepsy dataset
└── .gitattributes
```

## ▶️ Run it

1. Clone the repository.
2. Load a model from the all models/ folder with the framework it was saved in.
3. Use the files in dataset/ as input.
